# nævis 실행 안내 한 장 — 예제 모드

기준: 시작 틀 0.2.21 + `naevis-dashboard` 브랜치의 `a917bad645dcf3249faa9251198f46bafa25e58f`(4일차 백업). Windows 프로젝트 폴더에서 실행하며 포장하지 않습니다. **다른 사람의 안내만 보고 실행 시험은 아직 미확인**입니다.

## 1. 준비와 실행 위치

- Node.js **24.19.0**을 기준으로 준비합니다. 실행 도구는 22~24를 허용하며 **26은 실행을 중단**합니다. 기존 버전을 삭제할 필요 없이 공식 24.19.0 ZIP을 별도 폴더에 풀어 사용할 수 있습니다. 방법은 [상세 안내 13장](NAEVIS_DASHBOARD_GUIDE.md#13-5일차-본인의-별도-폴더-재현과-안내-보완)을 따릅니다. 관리자 권한 실행은 요구하지 않습니다.
- 제작자가 준비한 nævis 프로젝트의 **`on-client` 폴더**를 엽니다. 그 안에 `package.json`, `student/extension.mjs`, `tools/start-alekov.ps1`이 있어야 합니다. 프로젝트가 없다면 제작자에게 코드 폴더 준비를 요청합니다. 시작 틀 ZIP만으로는 nævis 학생 화면이 들어 있지 않습니다.
- 파일 탐색기에서 이 폴더를 연 뒤 **주소창에 `powershell` 입력 → Enter**. 아래 확인·실행 명령은 모두 이 창에서 입력합니다. **별도 폴더 시험에서는 기존 Workbench 창을 그대로 쓰지 말고 새 재현 폴더에서 엽니다.** 이번 재현 위치는 `%USERPROFILE%\Desktop\naevis-day5-repro\on-client`입니다. 다른 PC에서는 실제 준비한 위치를 사용합니다.
- **SDP 연결 파일·인증서·토큰·AI 열쇠는 필요 없습니다.** 개인 설정을 복사하거나 공유하지 않습니다. 기존 프로젝트·제출 폴더를 지우거나 덮어쓰지 않습니다.

## 2. 버전 확인 → 앱 실행

아래는 PowerShell **명령**입니다. 먼저 세 줄을 실행해 **작업 위치가 이번 시험 폴더인지**, 선택된 Node 경로와 버전이 맞는지 확인합니다.

```powershell
Get-Location
(Get-Command node -CommandType Application | Select-Object -First 1).Source
node --version
```

**위치가 다르거나 버전이 v24.19.0이 아니면 여기서 멈추고 위치·실행 환경을 먼저 준비합니다.** 아래 앱 실행 명령은 확인을 마친 같은 창에서 입력합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -Demo
```

ZIP 방식의 임시 PATH는 **설정한 PowerShell 창과 그 자식 프로세스에만 적용**됩니다. 창을 닫거나 새 창을 열면 다시 설정·버전 확인이 필요합니다. 현재 package.json에는 외부 의존성이 선언되어 있지 않아 이 절차에서 `npm install`은 실행하지 않습니다.

**정상 시작 신호:** `케셰브 예제: http://127.0.0.1:5189`와 앱이 켜졌다는 안내. PowerShell 창을 열어 둔 채 브라우저에서 **<http://127.0.0.1:5189/>**를 엽니다. 서버 응답만으로 SDP·AI 연결 성공을 뜻하지 않습니다. 같은 앱을 중복 실행하지 않습니다. **별도 폴더 시험 전에는 기존 앱의 서버 창에서 Ctrl+C로 종료**해 5189 포트를 비웁니다. 기존 앱 화면을 새 폴더 성공으로 기록하지 않습니다.

## 3. 화면 확인 — 실제 값과 예시를 구분

| 위치·행동 | 확인할 결과 |
|---|---|
| 보호 현황 → 학생 구현 표시 | 상단 카드 네 개, 핵심 기능 안내, 계정·기기·세션 상세 펼치기. `demo` 계정·기기·세션은 **예시 자료** |
| 보안 기록 → 학생 「기록 다시 조회」 | 대기 후 갱신 안내·응답 시각, 날짜별 집계와 목록의 건수 일치. 기록도 **예시 자료**이며 실제 사건이 아님. 학생 영역만 갱신됨 |
| 보호 현황 → 제공 「내 PC 확인」 | **앱을 실행한 PC의 실측값**, 단위와 「이 PC 마지막 실측」 시각. 읽지 못한 항목은 확인 불가와 이유. PC 조회 성공이 안전·SDP 연결 성공은 아님 |
| 제공 「도움정보 불러오기」 → 학생 SDP 연결 상태 | 예제 모드라면 **SDP 미연결 · 예제 모드로 실행 중**. 이 시연에서 예상한 상태. 조회 전에는 확인 불가 |

키보드는 Tab으로 버튼·상세 펼치기에 초점을 옮기고 Enter로 실행합니다. 기록 응답의 `checkedAt`은 PC 측정 시각이나 사건 발생 시각과 다릅니다. Windows 경고·오류 건수는 침해·공격 탐지 결과가 아닙니다. 이 안내에는 따라 맞춰야 할 PC 예시 수치가 없습니다.

## 4. 종료·재실행과 막혔을 때

종료는 **서버가 실행 중인 PowerShell 창에서 Ctrl+C**. ZIP 임시 환경을 사용했다면 창을 닫지 말고, 같은 `on-client`에서 2장의 위치·버전 확인 후 재실행합니다.

| 증상 | 다음 행동 |
|---|---|
| `node`를 찾지 못함·버전 오류 | 오류 원문 기록 후 상세 안내 13장으로 해당 창의 실행 환경 준비. 버전 검사 우회·기존 Node 삭제는 하지 않음 |
| 실행 도구 파일을 찾지 못함 | 1장의 세 파일이 있는 `on-client`인지 확인. 파일을 임의 생성하거나 다른 프로젝트를 덮어쓰지 않음 |
| 포트 사용 중 | 먼저 켠 이 앱의 서버 창에서 Ctrl+C 후 시험할 폴더에서 재실행. 다른 프로세스는 임의 종료하지 않으며 기존 화면으로 재현 성공을 대신하지 않음 |
| 사이트 연결 불가·`NETWORK_ERROR` | 서버 창이 켜져 있는지 확인하고 2장 명령으로 실행. 열린 화면의 기록 오류는 「기록 다시 조회」로 재시도 |
| PC 항목 확인 불가·권한 부족 | 항목과 이유를 그대로 기록. 0·정상·예시 값으로 대신 쓰거나 관리자 권한·방화벽 설정을 변경하지 않음 |

## 5. 따라 한 사람이 남길 기록

이번 시험은 **AI 도움을 받은 본인의 동일 PC·별도 폴더 재현**입니다. 보완 문서 적용 후 폴더 혼동을 다시 바로잡고, 위치·버전 확인이 포함된 AI 안내 명령으로 재실행했습니다. 서버 출력과 화면을 확인했으며 안내만으로 독립 실행·다른 사람 시험·새 PC 재현은 미확인입니다. **다른 사람 시험 / 본인 재현** 중 구분을 적고, 확인 날짜·시각·Node 버전·사용 폴더·실행 결과를 남깁니다. 막히면 **단계 번호 + 한 행동 + 오류 문구 원문**을 적습니다(비밀값 제외). 제작자가 안내/코드/환경 중 원인을 확인해 필요한 부분만 고친 뒤, 같은 절차로 다시 시험합니다. 수행하지 않은 시험은 미확인으로 남깁니다. 상세 기존 기록: [NAEVIS_DASHBOARD_GUIDE.md](NAEVIS_DASHBOARD_GUIDE.md).
